# db-migrator-releases

DB Migrator 릴리스 배포 채널 (설치 zip · app-image zip · 실행용 jar zip). 소스는 비공개 레포에서 관리됩니다.

DB Migrator는 SQL Server의 스키마와 데이터를 Tibero(또는 Oracle)로 옮기는 Windows용 데스크톱 도구입니다. 최신 버전은 **0.5.3**입니다.

- 테이블·컬럼·데이터·PK를 옮깁니다(0.1.0부터).
- 인덱스·UNIQUE·FK·CHECK·DEFAULT·시퀀스·시노님도 옮기고, 병렬 이관, 중단한 곳부터 이어서 실행, 스냅샷 격리 읽기, 창 없이 도는 명령줄(작업 스케줄러용)을 지원합니다(0.2.0부터).
- 뷰·함수·프로시저·트리거를 규칙으로 변환합니다(0.3.0부터, 생성형 AI는 쓰지 않음). 뷰와 스칼라 함수는 대상에 만든 뒤 원본과 결과를 비교해 같을 때만 남기고, 프로시저·트리거는 변환 초안을 만듭니다. 변환하지 못한 것은 원본과 초안을 파일로 꺼내 줍니다.
- 화면 기본 글꼴이 나눔고딕입니다(0.4.0부터, 프로그램에 포함).
- 설치 프로그램으로 설치한 사본은 앱 안에서 새 버전을 확인하고 설치합니다(0.5.0부터).
- 마법사를 `이전`/`다음`으로 한 단계씩 진행하고, 연결 정보를 저장합니다(0.5.1부터).
- 매핑 단계에서 대상에 이미 있는 테이블은 `기존 테이블 사용`, 없는 테이블은 `새로 생성`으로 정하고(0.5.2부터), 기존 테이블에 행이 있으면 사전 점검이 실행 전에 알려 줍니다(0.5.3부터).

> **Tibero 미검증 릴리스** — 실제 Tibero 서버로는 아직 검증하지 못했습니다. 0.2.0부터는 실제 Oracle Database Free 23으로 확인합니다.
> 자세한 내용은 각 릴리스의 노트를 확인하세요.

## 받는 방법

[Releases](https://github.com/fdrn9999/db-migrator-releases/releases)에서 최신 버전(Latest)을 받습니다.

exe 내려받기가 막힌 환경에서도 받을 수 있도록 **zip 파일만** 올립니다. 설치 프로그램도 zip에 담아 올립니다.

| 파일 | 용도 |
|---|---|
| `DB-Migrator-<버전>-setup.zip` | **설치해서 쓰려면 이것**을 받으세요(0.4.1부터). 압축을 풀면 나오는 `DB-Migrator-<버전>-setup.exe`를 실행합니다. 사용자 단위로 설치되어 관리자 권한이 필요 없고, Java가 없어도 됩니다(런타임 포함). 앱 안 업데이트는 이렇게 설치한 사본에서만 됩니다 |
| `DB-Migrator-<버전>-win-app-image.zip` | 설치 없이 쓰려면 이것을 받으세요. Java가 없어도 됩니다(런타임 포함). 압축을 풀고 `DB Migrator` 폴더의 `DB Migrator.exe` 실행. 관리자 권한이 필요 없고, 지울 때는 그 폴더를 지우면 됩니다 |
| `DB-Migrator-<버전>-jar.zip` | JDK 17 이상이 있는 경우. 압축을 풀고 `scripts\run.bat`(화면) 또는 `scripts\run-cli.bat`(명령줄, 0.2.0부터) 실행 |
| `SHA256SUMS.txt` | 위 파일들의 SHA-256 |

- 0.2.0~0.4.0에는 설치 프로그램이 없습니다. 0.1.0에는 설치 프로그램이 zip에 담기지 않은 exe로 있습니다.
- 명령줄은 jar 묶음으로만 실행할 수 있습니다(JDK 17 이상 필요). 설치한 프로그램과 app-image에는 명령줄용 실행 파일이 없습니다. 화면은 설치한 프로그램으로, 예약 실행은 jar 묶음으로 써도 설정·프로필을 함께 씁니다.
- 실행 파일에는 코드 서명이 없어, 처음 실행할 때 Windows가 경고(SmartScreen)를 띄울 수 있습니다.
- Tibero JDBC 드라이버가 함께 들어 있습니다. Oracle JDBC 드라이버는 들어 있지 않아, Oracle로 옮기려면 설정 화면에서 드라이버 jar를 지정합니다.

## 새 버전으로 올리기

- 0.5.0 이상을 설치 프로그램으로 설치했다면 **도움말 › 업데이트 확인…** 에서 새 버전을 받아 설치할 수 있습니다(창을 열 때도 알려 줍니다). 받은 파일은 그 릴리스의 `SHA256SUMS.txt`와 SHA-256이 같을 때만 실행합니다.
- 0.4.2 이하라면 0.5.0 이상을 한 번 직접 받아 설치하세요. 그 뒤로는 앱 안에서 올릴 수 있습니다.
- app-image와 jar 묶음은 새 버전이 있다고 알리고 릴리스 페이지를 열 수 있게만 합니다. 새 zip을 직접 받으세요.
- 설정·연결 프로필·저장한 비밀번호·로그·리포트(`%USERPROFILE%\.dbmigrator\`)는 그대로 씁니다.

## 설정과 비밀번호

설정과 로그는 `%USERPROFILE%\.dbmigrator\`에 저장됩니다. 비밀번호는 평문으로 어디에도 저장하지 않습니다. 연결 화면에서 "비밀번호도 저장"을 켠 경우에만 Windows DPAPI로 암호화해 저장합니다(0.5.1부터). 명령줄은 비밀번호를 환경 변수나 콘솔 입력으로만 받습니다.
